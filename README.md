Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/split-pdf.html](https://pdfjin.com/pages/split-pdf.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-split
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-split.git
cd pdfjin-split
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-split --help
```

Use in Python:
```python
import pdfjin_split
```
